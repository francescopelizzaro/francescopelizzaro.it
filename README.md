# francescopelizzaro.it

Sito di Francesco Pelizzaro, editor e consulente editoriale.

Pagina unica pubblicata con GitHub Pages sul dominio francescopelizzaro.it.

- `index.html`: la pagina, con stili e script inclusi
- `ritratto.webp`: il ritratto
- `og.jpg`: l’immagine di anteprima per i link condivisi
- `fonts/`: i caratteri (Source Serif 4, Figtree, Caveat, Alex Brush), ospitati qui invece che su Google Fonts
- `CNAME`: il dominio personalizzato
